## 컨테이너란?
컨테이너 기술은 애플리케이션 실행에 필요한 모든 요소들(OS, 소스코드, 구성요소, 종속성 등)을 하나의 런타임 환경으로 패키징한 논리적 공간을 말한다.

즉, OS + 애플리케이션를 가상화한 격리된 프로세스

Docker에서는 Dockerfile build를 통해 구현되어있다.

## 컨테이너 특징
- 경량화된 이미지를 통해 실행됨 -> 불필요한 프로세스 없음
- 프로세스 수준의 속도로 빠르게 실행 가능
- 한번에 여러 개의 컨테이너를 동시에 실행 가능
- 어떤 환경에서도 동작 가능한 이식성을 보유하고 있음


### 컨테이너의 종류
- 시스템 컨테이너
호스트 OS 위에 Ubuntu와 같은 배포판 리눅스 Image를 통해 배포되는 컨테이너로 
또다른 __VM__의 형태이다.
- 애플리케이션 컨테이너
단일 애플리케이션 서비스를 실행하기 위해 패키징된 컨테이너

## 가상화
- 서버, 스토리지, 네트워크, 애플리케이션 등을 가상화하여 하드웨어 리소스를 효율적으로 사용하는 것이 목적
- 물리적 하드웨어 유지 관리 대신 소프트웨어적으로 추상화 된 가상화를 통해 쉽게 관리하고 유지 가능
- 하이퍼바이저 기반의 가상머신을 통해 수행

### 그럼 컨테이너 가상화 vs VM 가상화 뭐가다름?
- 둘다 실행하려는 애플리케이션과 그 종속 요소들을 패키지하여 호스트와 격리된 환경을 제공
- VM 가상화는 실제 GuestOS를 두고 애플리케이션을 설치하는 형태 (하드웨어 수준의 가상화)
- 컨테이너는 VM대비 경량이고, 호스트OS와 커널을 공유하는 운영체제 수준의 가상화

## Docker
이러한 컨테이너들을 실행하고 관리하는 container runtime 도구이다.
GitHub과 유사한 방식으로 Docker Hub에서 이미지를 제공한다.
이미지를 기반으로 컨테이너화 가능
