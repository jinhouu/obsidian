# ZooKeeper
ZooKeeper는 Broker/Topic/Partition 들의 목록/설정/상태 등을 관리하는 소프트웨어

- 변경사항에 대해 Kafka에게 알림
	-> Topic의 생성/제거, Broker 추가/제거 등
- ZooKeeper 없이는 Kafka가 동작 불가능 ( ZooKeeper mode 한정 종속적임)
- ZooKeeper는 홀수 개의 서버로 작동하게 설계되어 있음 (최소 3, 권장 5)
- ZooKeeper에는 Leader(writes)가 있고 나머지 서버는 Follower(reads)

# KRaft

이를 해결하기 위해 KIP-500 (Kafka Improvement Propasal) 을 통해 ZooKeeper 종속 제거
