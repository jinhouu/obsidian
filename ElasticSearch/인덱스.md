- **인덱스**는 논리적인 데이터의 모음으로, 하나 이상의 **샤드(shard)**로 구성됩니다.
- 문서(Document)는 JSON 형식으로 저장되며, 각 문서는 특정 **인덱스에 속함**.

|구성 요소|설명|비유|
|---|---|---|
|**Index**|문서들의 집합|데이터베이스(DB)|
|**Document**|실제 데이터(JSON 형태)|행(Row)|
|**Field**|문서 내의 키(key)|컬럼(Column)|
|**Mapping**|필드의 타입 정의|스키마(schema)|
|**Shard**|인덱스를 물리적으로 분리한 단위|파티션(partition)|
|**Replica**|샤드의 복제본|백업(Replication)|

이미 생성된 매핑 구조는 삭제나 변경이 불가능
새로운 인덱스를 생성하여 변경된 정보로 매핑 추가
모든 문서를 재색인 (신규 데이터 추가 및 기존 인덱스에서 신규 인덱스로 이관)
신규인덱스 데이터 확인
이전 인덱스 삭제
